# Lista de Tarefas Simples

Pequeno projeto front-end que implementa uma lista de tarefas (to‑do list) simples usando HTML, CSS e JavaScript puro.

## Descrição

Este projeto fornece uma interface mínima onde o usuário pode adicionar tarefas através de um campo de entrada e um botão. As tarefas aparecem em uma lista; ao clicar em uma tarefa ela é removida. Também há mensagens visuais indicando quando a lista está vazia ou quando o usuário tenta adicionar uma tarefa vazia.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6)

## Como usar

1. Abra `index.html` no seu navegador (duplo clique ou arraste para a janela do navegador).
2. Digite uma tarefa no campo de entrada.
3. Clique no botão para adicionar a tarefa.
4. Clique em uma tarefa na lista para removê-la.
